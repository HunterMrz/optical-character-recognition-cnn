# Optical Character Recognition Using CNN and Transfer Learning

## Overview

This project focuses on Optical Character Recognition (OCR) using deep learning models for character classification. The goal is to classify alphabetic character images using a custom CNN model and multiple transfer learning architectures.

## Results

The project compared multiple CNN and transfer learning models for OCR-based character classification.

| Model          | Accuracy | Precision | Recall | F1-score |
| -------------- | -------: | --------: | -----: | -------: |
| Custom CNN     |     0.95 |      0.96 |   0.95 |     0.95 |
| EfficientNetB7 |     0.93 |      0.94 |   0.93 |     0.93 |
| MobileNetV2    |     0.71 |      0.72 |   0.71 |     0.71 |
| VGG19          |     0.96 |      0.96 |   0.96 |     0.96 |
| DenseNet121    |     0.95 |      0.95 |   0.95 |     0.95 |
| ResNet50       |     0.94 |      0.94 |   0.94 |     0.94 |

## Project Description

The dataset was prepared using image preprocessing and data generators. A custom CNN model and several transfer learning models were trained and evaluated for character recognition. The models were compared using accuracy, precision, recall, and F1-score.

The best-performing model was VGG19, achieving approximately 96% accuracy.
